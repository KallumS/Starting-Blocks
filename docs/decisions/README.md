# Decision records

One file per decision that would otherwise have to be re-argued from scratch.
Numbered in the order they were taken, and **not rewritten afterwards**: a
decision that gets reversed keeps its record and gains a note pointing at the
one that replaced it. The point is to be able to read why something is the way
it is, including when the answer is "we tried the other thing first".

What belongs here: a choice with a real alternative, where picking the other
option would have produced a visibly different codebase. What does not: a
preference with no consequence, and anything already explained where it lives -
`CLAUDE.md` holds the standing rules, this holds the decisions behind them.

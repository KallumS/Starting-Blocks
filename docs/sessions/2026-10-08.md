# Session log - 2026-10-08

## What changed

**The Bass and Drums blocks were removed** from the list of blocks, with
everything that existed only for them: two generators, two tables, two panels,
five settings. Decision: [0006](../decisions/0006-remove-the-bass-and-drums-blocks.md).
The window now offers Chord, Arpeggio, Run and Melody.

The same engine change went into Starting Blocks Notation in the same session,
so `sb_engine.lua` is still byte-identical in both.

## How it went

**Every doc in both repositories was read first**, at the user's request, and
it mattered. Three things in them decided the shape of the change: the engine
is copied unchanged between the two apps, so it is changed once and copied;
Noterator had already hidden these blocks in its adapter and edits none of its
engine copies, so it needed nothing; and "Arpeggios and bass notes read the
chord you set in the Chord tab" is the line that shows the Bass block only ever
*read* the chord.

**The user's warning was the right one:** there might be code deciding where the
bass of a chord sits. There is - the chord's inversion, `st.inv`, through
`M.chordTones`. The Bass block called `M.chordTones(st, st.degree, 0)` and took
one tone from it; nothing flows the other way. Every removed line was checked
against that before it went, and the chord, inversion and arpeggio tests were
left exactly as they were and still pass.

**Tests that borrowed a removed block were moved, not dropped.** The rate and
gate checks used a Bass block because it is one note at a time; a held melody
note is the same thing now. The MIDI-range check used a bass two octaves down;
a run at the lowest octave reaches lower still. The settings round-trip used
Drums as "not the default block"; it uses Melody. The slider sweep's note about
hidden controls pointed at the drums; Melody's held note hides controls too.

**New assertions, each broken on purpose first:** the list of kinds is named
rather than counted; a setting saved on Bass or Drums opens on the chord in the
engine and in the window; and the settings only those blocks used are not
written back. Putting Bass back in the list, removing the unknown-name fallback,
and saving `shuffle` again each failed them.

The engine suite went from 883 checks to 471 and the UI suite from 237 to 173.
Nearly all of that is the drum tests, whose shuffle sweep counted a check per
hit.

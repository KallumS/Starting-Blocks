# 2026-11-10 - Ableton Live device

The user is switching to Ableton and asked for each REAPER project as Max
for Live, one branch per repository. Branch `ableton`.

- Built the shared kit (`ableton/kit/`): Middaw's Lua runtime, a `[v8ui]`
  window for any engine with an adapter, Live clip reading and writing, a
  player, and `build.py` for the `.amxd`, `.maxpat` and bundle.
- Starting Blocks is the first device. Ten tests in Node on a pretend Max and
  Live: every setting stepped through, hearing a block (every note started is
  stopped), insert into a new clip, a full track refused, the Arrangement, the
  open clip, Live's scale followed and spelled (G# minor, Ab major), state
  saved and restored before and after Live is ready.
- Not done: opening it in Live. See decision 0011.

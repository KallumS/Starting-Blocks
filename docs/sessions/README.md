# Session logs

What happened in a working session, written at the end of it: what changed, what
was tried and abandoned, what broke, and what was left open. One file per
session, named for the day it was written up.

These are a **narrative**, and they go stale on purpose - a log is never edited
to match what the code later became. For what is true now, read `CLAUDE.md`. For
why a decision was taken, read [`../decisions/`](../decisions/). For what
happened on a given day, read these.
